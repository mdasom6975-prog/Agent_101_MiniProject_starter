## 4. Requirements

### store.py
- `__init__`은 입력을 **deep copy**해서 `books: dict[str, Book]`, `members: dict[str, Member]`, `holds: dict[str, list[str]]`, `today`를 만든다. (T103, T109)
- `holds`는 book_id별 예약 대기열이다. members.json의 holds를 **파일 순서대로** 쌓는다.
- `from_dir()`과 `load_store()`는 data 폴더의 JSON을 읽어, 호출할 때마다 **독립된 인스턴스**를 반환한다. (T103)
- `search_books()` (T104–T107)
  - query, title, author를 **소문자화하고 공백을 지운 뒤**, query가 title 또는 author의 부분 문자열인 도서를 찾는다.
  - 빈 query는 전체를 뜻한다.
  - genre는 완전 일치로 거른다. `available_only=True`면 `available > 0`인 도서만 남긴다.
  - 결과는 **id 오름차순**으로 앞에서 limit개다. 없으면 `[]`.
- `get_book`, `get_member`는 없는 ID에 `BookNotFoundError`, `MemberNotFoundError`를 raise한다. 메시지는 `MESSAGES[code].format(...)`로 만든다. (T108)
- `loan_limit` = `LOAN_LIMITS[member_type]` (일반 5, 신규 3)
- `member_status`: `current_loans = len(loans)`, `loan_limit`, `holds` = 이 회원이 대기열에 있는 book_id 목록(오름차순). (T109)

### tools.py
- `make_catalog_tools(store)`는 `[search_books, get_book_detail]` 순서의 `@tool` 목록을 반환한다. **docstring은 한국어**로 쓴다. (T121)
- `search_books(query: str = "", genre: Genre | None = None, available_only: bool = False)` (T122, T123, T126)
  - 반환: `json.dumps([book.model_dump(), ...], ensure_ascii=False)`
  - 결과 없음: `NO_BOOKS`
  - 잘못된 genre는 `ValidationError`
- `get_book_detail(book_id: str)`: `Book.model_dump()`에 `hold_queue`(예약 대기 인원)를 더한 JSON 객체를 반환한다. 없는 ID는 오류를 **그대로 raise**한다. (T124, T125)

## 6. 구현 시 주의점

- 형식 검사를 `list[Annotated[str, Field(pattern=...)]]`로 하면 T116이 기대하는 메시지가 나오지 않는다. 메시지는 `field_validator` 안에서 `ValueError`로 직접 만든다.
- 개수 제약(1–5)은 `Field(min_length=1, max_length=MAX_BOOKS_PER_REQUEST)`로 건다.
- deep copy가 없으면 T103이 실패한다. 인스턴스끼리 Book·Member 객체를 공유하지 않게 한다.
- `from __future__ import annotations`가 켜진 상태라, @tool이 `Genre` 타입 힌트를 해석하려면 **tools.py에서 `Genre`를 import**해야 한다.
- 도구 안에서 `try/except LibraryError`를 쓰지 않는다. 오류를 ToolMessage로 바꾸는 일은 M4 middleware가 맡는다.
- `search_books` 도구에는 `limit` 인자가 없다. store 기본값 5가 적용된다.
