# 책숲 AI 사서 Agent — 마일스톤별 체크리스트 & 이틀 작업 계획

> 출처: `docs/Agent_101_MiniProject_책숲_AI사서_명세서.pdf` (v2.0)

## 먼저 알아둘 것

- 이 폴더는 아직 git 저장소가 아니다. 제출 체크리스트에 "`git status`에 `tests/`, `data/`, `eval/eval_cases.json` 변경이 없다"는 항목이 있으므로, 시작 전에 `git init`과 baseline 커밋을 해 둔다.
- 시스템 Python은 3.14다. `.venv`의 Python 버전과 `requirements.txt`(langchain 1.4.7, langgraph 1.2.19)가 잘 설치되는지 먼저 확인한다.
- M2·M3의 agent 테스트가 `default_middleware()`를 쓴다. 그래서 M2 단계에서 middleware 일부를 **최소한으로 먼저** 만들고, M4에서 완성한다 (명세서 2.6절).
