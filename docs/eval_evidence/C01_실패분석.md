## 2. 실패 case

- 질문: 『숲속의 작은 서점』 지금 빌릴 수 있나요?
- 기준: expected_tools = `ask_catalog_agent`, `search_books` / must_contain = `B001`
- trial1 판정: `missing_tools=[] forbidden=[] missing_keywords=['B001']`

## 3. Trace 근거

보존 파일: `C01_trial1_fail.jsonl` (실패), `C01_trial2_pass.jsonl` (통과)

| 단계 | trial1 (실패) | trial2 (통과) |
|---|---|---|
| catalog_agent `search_books` 출력 | `[{"id": "B001", "title": "숲속의 작은 서점", ... "available": 2}]` | 동일 |
| supervisor → `ask_catalog_agent` 의 request | "제목이 『숲속의 작은 서점』인 책을 찾아 주세요. 지금 대출 가능한 재고(available)가 있는지 확인해 주세요." | "...책이 지금 대출 가능한지 확인해 주세요. **도서 ID와** 현재 대출 가능한 재고(available)도 알려 주세요." |
| catalog_agent 의 답 | `- **B001 — 『숲속의 작은 서점』**, 한서윤: 지금 대출 가능한 재고는 **2권**입니다.` | `... 도서 ID는 **B001**, 저자는 한서윤, 현재 대출 가능한 재고(available)는 **2권**입니다.` |
| **최종 답** | `네, 『숲속의 작은 서점』은 지금 **2권** 대출 가능합니다.` ← **B001 없음** | `... 도서 ID는 **B001**이고, 현재 대출 가능한 재고는 **2권**입니다.` |

## 4. 원인 분류

| 후보 | 판정 | 근거 |
|---|---|---|
| 라우팅 실패 | 아님 | 세 trial 모두 `search_books` → `ask_catalog_agent` 호출 |
| 도구가 틀린 값 반환 | 아님 | `search_books`가 B001을 정확히 반환 |
| subagent(catalog)가 ID를 누락 | 아님 | trial1에서도 catalog 답에 `B001`이 있음 |
| **supervisor가 최종 답에서 ID를 생략** | **원인** | catalog 답의 `B001`을 supervisor가 "2권 대출 가능"으로 줄이면서 뺌 |

보조 요인: trial1의 supervisor request에는 "도서 ID도 알려 달라"는 요청이 없었다. (trial2·3은 포함)

기존 `SUPERVISOR_PROMPT` 6번은 "숫자, 조항, 도서 ID, 금액을 바꾸거나 빼지 않고 최종 답에 그대로 포함"이라고 이미 적고 있었지만, 규칙이 여러 항목의 나열 속에 있어 짧게 요약하는 답에서는 지켜지지 않았다.

## 5. 수정 (agents.py의 prompt만 수정, 일반 규칙)

`SUPERVISOR_PROMPT`
- 3번: 도서에 대해 물을 때 **도서 ID와 대출 가능한 재고(available)도 함께 알려 달라고** request에 적는다.
- 6번: 도서를 언급하는 최종 답에는 담당 agent 답에 나온 **도서 ID(B000 형식)를 반드시 포함**하고, 답을 짧게 줄이려고 ID·숫자·조항을 생략하지 않는다.

(특정 질문 문자열에 맞춘 정답을 넣지 않고, 도서 질문 전반에 적용되는 규칙이다.)
